# OKF Workbench 0.3.0 release record

OKF Workbench `0.3.0` was released on 2026-08-03 from signed tag `v0.3.0`. This
record binds the publication and post-publication checks to the exact revisions and artifacts
below; it does not qualify later source changes.

## Scope

The release adds OKF v0.2 metadata semantics and Attested Computation support while retaining a
guarded v0.1 compatibility fallback. It also adds an explicit, previewed v0.1-to-v0.2 extension
migration workflow and the preview-only `okf migrate --check` CLI command.

## Rollback

Open VSX versions are immutable. Preserve the artifacts and evidence and fix forward with a higher
SemVer version for a defective non-security release. For a security, privacy, credential, or
licensing incident, revoke credentials, use the private security route, contact Open VSX for the
exact version, and publish clear update or uninstall guidance.
