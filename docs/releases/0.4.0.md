# OKF Workbench 0.4.0 release record

Status: Published and verified on 2026-09-05; remaining platform/credential scope is recorded below.

## Scope

Node 24/CommonJS Extension Host output, `@types/node` 24.13.3, VS Code 1.123 minimum,
and VSCodium 1.126.04524 qualification, as accepted in [ADR 0012](../decisions/0012-node24-extension-host.md).
Development dependency updates include undici, fast-uri, js-yaml, postcss, and nanoid.
The format semantics, local-first behavior, Wasm ABI, and native CLI features are unchanged.

Windows watcher events now compare canonically serialized VS Code URIs so `/C:/` roots
accept `/c:/` events while retaining containment checks. Valid UTF-8 documents within
the source-size limit cross the Wasm JSON ABI as strings. Malformed and oversized byte
inputs retain their original diagnostics. Regression coverage includes BOM, CRLF,
Unicode, invalid UTF-8, source-size boundaries, and all watcher event types.

Release compilation uses optimization level 3 with existing LTO and one codegen unit.
Provider operations use fixed batches of sixteen, retaining the per-document/aggregate
byte limits, parent-generation checks, and draining of canceled physical calls. The
headed runner supports Windows process counters, CLI invocation, and signaled process exit.
Performance thresholds and the 250 ms watcher debounce are unchanged.
