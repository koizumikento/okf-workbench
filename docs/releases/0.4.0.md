# OKF Workbench 0.4.0 release record

Status: All candidate qualification gates pass; awaiting reviewed main and tag publication.

## Scope

Node 24/CommonJS Extension Host output, `@types/node` 24.13.3, VS Code 1.123 minimum,
and VSCodium 1.126.04524 qualification, as accepted in [ADR 0012](../decisions/0012-node24-extension-host.md).
Development dependency updates include undici, fast-uri, js-yaml, postcss, and nanoid.
The format semantics, local-first behavior, Wasm ABI, and native CLI features are unchanged.

Windows watcher events now compare canonically serialized VS Code URIs so `/C:/` roots
accept `/c:/` events while retaining containment checks. Regression coverage includes
create/change/delete, nested Unicode/spaced paths, siblings, and other drives.
Valid UTF-8 documents cross the existing Wasm JSON ABI as strings instead of numeric
byte arrays; invalid UTF-8 retains the byte path and original diagnostics. Tests cover
BOM, CRLF, Unicode, and malformed UTF-8.

The headed runner supports Windows process counters, the editor's CLI wrapper, and
signaled process exit. It measures the same canonical Wasm used by hosted packaging,
with its CI receipt and current Rust input hashes checked before building. Both files
are included in the immutable measurement inputs. Thresholds and debounce are unchanged.
