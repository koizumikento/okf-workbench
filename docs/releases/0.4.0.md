# OKF Workbench 0.4.0 release record

Status: Preparing; no 0.4.0 tag or package has been published.

## Scope

Node 24/CommonJS Extension Host output, `@types/node` 24.13.3, VS Code 1.123 minimum,
and VSCodium 1.126.04524 qualification, as accepted in [ADR 0012](../decisions/0012-node24-extension-host.md).
Development dependency updates include undici, fast-uri, js-yaml, postcss, and nanoid.
The format semantics, local-first behavior, Wasm ABI, and native CLI features are unchanged.

The release candidate also enables the existing headed-evidence runner to read Windows
process CPU/working-set counters and invoke the editor CLI without a command-shell wrapper.
CPU/working-set values remain environment-specific observations.

## Qualification and publication

Current candidate receipts are pending. Results for PR #47 and published 0.3.0 are
predecessor evidence and are not reused as proof for the 0.4.0 bytes.

Follow [the release checklist](../release-checklist.md) before creating a signed tag.
