## Changes since 0.4.1

The renderer advances from 3d-force-graph 1.80.1 to 1.80.2, with refreshed
production notices. Development tooling advances to VSCE 4.1.0,
typescript-eslint 8.72.1, Vitest 5.1.0, and Playwright 1.65.0. Reviewed

[ADR 0013](../decisions/0013-development-tooling-security-updates.md).

are introduced by this release preparation.

## Remaining merge and publication gates

The qualified candidate is not merged, tagged, or published. Protected review/merge,
any required deployment approval, successful final-main checks, and absent-version
checks remain required. This evidence-only follow-up changes excluded documentation;
it requires latest-head CI before protected merge. Do not infer approval or publication
from successful candidate qualification.

Only after those gates may `v0.4.2` be tagged through the normal workflow. Public
GitHub/Open VSX downloads, all checksums, standalone/bundled CLI parity, and
package-manager manifests must then be independently verified. Fresh publication
bytes must match the qualified runtime; record platform-native build differences
explicitly rather than reusing an older hash. Live post-publication Homebrew/Scoop
installation is not claimed by prepublication smoke or manifest generation.
