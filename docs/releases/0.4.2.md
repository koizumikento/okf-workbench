production notices. Development tooling advances to VSCE 4.1.0,
typescript-eslint 8.72.1, Vitest 5.1.0, and Playwright 1.65.0. Reviewed
lockfile updates and glob/minimatch overrides address development-only qs

[ADR 0013](../decisions/0013-development-tooling-security-updates.md).
No format contract, MVP scope, API floor, or local-only product boundary changes
are introduced by this release preparation.

## Pending qualification and publication

All release-specific evidence gates are pending. The version change modifies the
Wasm source-input identity; older 0.4.1 receipts and pre-bump PR checks cannot
qualify 0.4.2. Retain exact candidate commit, original build receipt, full VSIX
and runtime hashes, raw lifecycle JSON, and headed performance capture before
updating the [release checklist](../release-checklist.md).

Required work includes exact-head CI, nine Compatibility jobs using the genuine
published predecessor, six Package smoke jobs, and genuine headed Windows
performance/network capture passing the unchanged strict evaluator. Compare the
measured runtime bytes with the final universal and platform packages. Preserve
failed observations and distinguish fixture-upgrade CI from release qualification.

Only after those gates, protected review/merge, and successful main checks may
`v0.4.2` be tagged through the normal workflow. Public GitHub/Open VSX downloads,
all checksums, standalone/bundled CLI parity, and package-manager manifests must
then be independently verified. Record actual post-publication lifecycle tests
separately; manifest publication alone does not prove live Homebrew/Scoop install.
