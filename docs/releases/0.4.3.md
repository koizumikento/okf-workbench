# 0.4.3 release record

- Status: Published on 2026-11-25; distribution and package checksums verified.
- Scope: Reviewed development tooling and test-infrastructure changes since published
  0.4.2. No API floor, application behavior, performance threshold, or security-boundary change.
- Release route: matching annotated tag on reviewed main via [ADR 0006](../decisions/0006-publish-open-vsx-from-version-tags.md).
- API floor: VS Code `^1.123.0`; compile-time types `1.120.0`.
- Qualification: VS Code 1.123.0 minimum, VS Code 1.148.0 current, VSCodium
  1.143.17232 (Extension Host API 1.143.1).
- Node 24.18.0, npm 11.16.0, and Rust 1.92.0.
